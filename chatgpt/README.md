# Ayu Terminal Dark for ChatGPT desktop

[Native theme preset](ayu-terminal-dark.theme): Ayu canvas `#0B0E14`, warm text `#E8E6DD`, lilac accent `#D2A6FF`.
Native UI and reading fonts pair with JetBrainsMono Nerd Font for code (monospace fallback).
Contrast is 55; opaque windows keep the background consistent with the terminal.

1. Open Settings > Appearance > Advanced.
2. Copy the existing dark theme with Copy theme and save the string as a backup.
3. Select Dark, then click the dark theme Import button.
4. Paste the entire line from `ayu-terminal-dark.theme` and submit Import theme.

Only the dark preset is imported. The theme has not been applied or visually verified in this session because desktop control is unavailable.
